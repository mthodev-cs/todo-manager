# To-Do List Manager

A console to-do app written in Java.

## Features
- Add, list, complete, and delete tasks
- Tasks are saved to a file and loaded when the program starts
- Handles invalid input without crashing

## How to run
1. Compile: `javac src/*.java`
2. Run: `java -cp src Main`

## What I learned
- Classes, constructors, and encapsulation
- ArrayList and loops
- File I/O with `java.nio.file.Files`
- Exception handling with try/catch
